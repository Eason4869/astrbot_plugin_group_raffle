# 群抽奖助手 GroupRaffle

[![浏览次数](https://count.getloli.com/@astrbot_plugin_group_raffle?name=astrbot_plugin_group_raffle&theme=minecraft&padding=6&offset=0&align=top&scale=1&pixelated=1&darkmode=auto)](https://count.getloli.com/@astrbot_plugin_group_raffle)

</div>

AstrBot 群聊抽奖插件：**每个群独立配置**，支持手动/定时开奖、三种参与模式、多等次多名额、活跃度加权、防连中、@中奖者、自定义消息模板和开奖卡片。

> 包名：`astrbot_plugin_group_raffle`

## ✨ 功能一览

- **分群独立配置**：定时、等次名额、参与模式、模板、卡片开关等全部按群保存，互不影响，重启自动恢复
- **手动开奖**：`抽奖 开奖 [人数]`，管理员随时触发
- **定时开奖**：每日 / 每周 / 每两周 / 每月 / 自定义 cron，支持下次触发时间预览
- **三种参与模式**
  - `等权`：从插件观测到的本群发言成员中随机抽取（无需报名）
  - `加权`：按近 N 天发言活跃度加权（`权重 = 基础值 + k × √(有效消息数)`，防刷屏压缩），无人达标自动回落等权
  - `报名`：群友发送「抽奖 报名」参与，开奖后自动清场进入下一场次
- **中奖等次**：可设多等次、每等次多名额，例如 `一等奖:1,二等奖:2,三等奖:3`；同一人不会重复中奖
- **防连中**：中奖后 N 天冷却期内不再被抽中（可关闭）；可选排除管理员
- **@ 中奖者**：支持真实 @（OneBot 系：NapCat / Lagrange / LLOneBot 等），不支持的平台自动降级为文本昵称
- **自定义中奖模板**：占位符 `<winners> <count> <group> <time> <contact>`
- **开奖卡片**：安装 [astrbot_plugin_htmlrender](https://github.com/AstrBotDevs/astrbot_plugin_htmlrender) 后渲染 HTML 卡片；未安装自动降级为 Pillow 本地简版卡片，再降级为纯文本。**真实 @ 始终在卡片之外，不渲染进图片**
- **隐私友好**：活跃度只统计「群+用户+天」的消息条数，**不保存消息正文**，支持自动清理
- **群名单控制**：全局白名单/黑名单模式 + 群级启用/停用开关

## 📦 安装

1. 在 AstrBot 插件市场搜索 `group_raffle` 安装，或手动将本仓库放入 `data/plugins/astrbot_plugin_group_raffle`
2. 依赖 `APScheduler` 会自动安装；卡片为可选能力（见上）
3. 在 WebUI 配置页填写全局设置（管理员、默认模板、联系方式、防刷参数等）
4. 在群里由管理员发送「抽奖 启用」开启本群

## 🎮 命令

主命令：`抽奖`（英文别名 `raffle`，两者完全等价，如 `/raffle 开奖`）。

| 命令 | 权限 | 说明 |
|---|---|---|
| `抽奖 帮助` | 所有人 | 查看全部命令 |
| `抽奖 状态` | 所有人 | 查看本群配置与未来开奖时间 |
| `抽奖 报名` / `抽奖 取消报名` | 所有人 | 报名模式下参与/退出 |
| `抽奖 名单` | 所有人 | 查看报名名单 / 活跃榜 / 已观测成员 |
| `抽奖 启用` / `抽奖 停用` | 管理员 | 本群开关（停用同时暂停定时） |
| `抽奖 开奖 [人数]` | 管理员 | 立即开奖（真实生效）；可临时指定人数 |
| `抽奖 模拟 [人数] [轮数]` | 管理员 | 模拟开奖测试效果：不记录中奖、不清报名、不 @、不发卡片，可反复执行，如 `抽奖 模拟 3 5` |
| `抽奖 模式 等权\|加权\|报名` | 管理员 | 参与模式 |
| `抽奖 等次 一等奖:1,二等奖:2` | 管理员 | 设置等次与名额 |
| `抽奖 冷却 7` | 管理员 | 防连中冷却天数（0 关闭） |
| `抽奖 排除管理员 开\|关` | 管理员 | 开奖是否排除管理员 |
| `抽奖 艾特 开\|关` | 管理员 | 是否 @ 中奖者 |
| `抽奖 卡片 开\|关` | 管理员 | 是否渲染开奖卡片 |
| `抽奖 模板 <文本>` | 管理员 | 中奖消息模板 |
| `抽奖 窗口 7` | 管理员 | 活跃度统计窗口天数 |
| `抽奖 定时 关` | 管理员 | 关闭定时 |
| `抽奖 定时 每日 20:00` | 管理员 | 每日定时 |
| `抽奖 定时 每周 周一 20:00` | 管理员 | 每周定时（0-6，0=周一） |
| `抽奖 定时 双周 周一 20:00` | 管理员 | 每两周定时 |
| `抽奖 定时 每月 1 20:00` | 管理员 | 每月定时（日期建议 1-28） |
| `抽奖 定时 cron 0 20 * * 5` | 管理员 | 自定义 5 段 cron（分 时 日 月 周） |
| `抽奖 定时预览` | 所有人 | 预览未来 3 次开奖时间 |

### 模板示例

```
抽奖 模板 🎉 恭喜 <winners> 中奖！请于三日内联系管理员领取奖品～（<time>）
```

占位符：`<winners>` 中奖者名单、`<count>` 中奖人数、`<group>` 群号、`<time>` 开奖时间、`<contact>` 全局配置的联系方式。

## ⚙️ 全局配置（WebUI）

- 群启用模式：黑名单（默认全开）/ 白名单
- 群白名单 / 黑名单群号
- 额外管理员列表（群主和群管理员自动有权限）
- 默认卡片开关、默认 @ 开关、默认模板、联系方式
- 新群默认参与模式
- 防刷：每日有效消息上限（默认 30）、最小消息间隔秒数（默认 5）
- 活跃度明细保留天数（默认 60）

## 🧠 设计说明

- **候选池来源**：QQ 官方机器人无「获取群成员列表」接口，等权/加权模式从插件观测到的发言成员中抽取；报名模式则完全不依赖观测。新群冷启动建议先用报名模式或等群友发言积累。
- **加权算法**：`权重 = base + k × √(窗口内有效消息数)`，开平方抑制刷屏；每日条数封顶 + 短间隔消息不计入，双重防刷。
- **定时持久化**：定时任务存在各群配置里，插件启动时全量重建；停机期间错过的开奖不补发（`misfire_grace_time=3600`，`coalesce`）。
- **数据**：SQLite（`raffle.db`），含观测成员、按天活跃度、报名、中奖记录、开奖流水、分群配置。
